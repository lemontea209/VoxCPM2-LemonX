# VoxCPM2 整合包 · Lemon-X 修改版

**本修改版版本：v2.15.0**

基于 [OpenBMB/VoxCPM](https://github.com/OpenBMB/VoxCPM) 的 Windows 便携式语音合成整合包，
在余子越制作的 YZY 启动器与原整合包基础上二次修改。开箱即用，无需配置 Python 环境。

> 本项目与 OpenBMB、ModelBest、阿里巴巴集团、FunAudioLLM / FunASR、OpenAI、FFmpeg、
> Electron 及其他第三方项目**不存在隶属或背书关系**。

---

**本仓库只存放本修改版的源码与许可证文档**，供查阅、核对与二次开发：

| 目录 | 内容 |
| --- | --- |
| `src/` | 本修改版的 Python 源码（对应整合包 `win-unpacked/python/` 下的同名文件） |
| `src/voxcpm/` | 相对上游 OpenBMB/VoxCPM 修改过的文件，文件头带 Apache 4(b) 修改声明 |
| `launcher/` | 启动脚本与使用说明 |
| `LICENSES/` | 第三方模型许可证全文 |

这些文件单独取出**无法直接运行**，需要放回整合包对应位置。

## 快速开始（下载整合包之后）

解压后双击 `启动.bat`。若无法运行，先双击 `系统检测.bat` 查看系统组件版本，

**解压提醒：** 必须使用 7-Zip，且解压路径不能含中文。

## 功能

### 本地语音合成

- **本地配音** —— VoxCPM2 本地推理，不联网、不需要 API
- **音色克隆** —— 上传参考音频后自动转写参考文本（SenseVoice），不用手打
- **参考音频自动裁剪** —— 超出推荐时长（10–20 秒）的参考音频自动截取后再识别
- **音色库** —— 内置预设音色；可保存自己的音色并命名，也可真实删除
- **本地音色设计** —— 用文字描述音色特征直接生成，不需要参考音频
- **长文本分段生成** —— 按标点与长度自动切分，规避单次推理的长度限制
- **段间响度对齐** —— 分段拼接前统一各段电平，消除段与段之间的音量跳变
- **多角色配音** —— 一段文本中按角色切换不同音色
- **SRT 字幕配音** —— 导入 `.srt`，按时间轴逐条生成

### 云端语音合成（MiniMax，需自备 API Key）

- **云端配音** —— 调用 MiniMax TTS，本机不需要显卡
- **云端音色克隆** —— 上传音频生成云端 `voice_id`
- **云端音色设计** —— 文字描述生成多个候选音色，试听后择一保存
- **云端音色库** —— 保存的音色在本机留存；删除时云端与本机一并删除
- **模型列表自动拉取** —— 从你账号当前可用的模型中选择
- **字符计数** —— 生成前显示字符数，便于估算调用量
- **行间停顿控制** —— 按行插入可调节的停顿

### 输出与后处理

- **任务队列** —— 多任务排队执行，可中途停止
- **生成历史** —— 分页浏览、按需加载试听；清空时文件移入回收站而非直接抹除
- **字幕识别** —— Whisper 生成字幕
- **时间轴音频导出** —— 导出 WAV / MP3，MP3 可选码率
- **变速** —— WSOLA 时间伸缩（注意事项见下方「关于语速调节」）

### 其他

- 明暗主题适配
- API Key 以 Windows DPAPI 加密存放于用户目录，不在整合包内（详见下文）
- 全进程直连、不走系统代理，避免代理软件拦截本地启动检查与云端 API 请求
- 运行日志落盘，并单独保留上一次运行的日志，便于排查问题

## 相对余子越原版整合包的改动

本修改版为 **v2.15.0**，在余子越 **V1.0** 整合包基础上迭代。

> 注意区分两条版本线：`VoxCPM 2.0` 是 OpenBMB 官方公开的上游模型版本；
> `v2.15.0` 是本整合包（二次修改版）自己的版本号。二者无对应关系。

### 新增

| 功能 | 说明 |
| --- | --- |
| MiniMax 云端 TTS | 原版没有任何云端功能。新增整个云端页，含「云端配音」「云端音色设计」两个子页 |
| 云端音色克隆与音色库 | 上传音频生成 `voice_id`，本机留存音色库；删除时云端 + 本机一并删除 |
| API Key 安全保存 | DPAPI 加密落盘，存放于 `%LOCALAPPDATA%`，不在整合包目录内 |
| 段间响度对齐 | 原版分段独立生成、拼接前无电平对齐，实测段间响度极差 5.5 dB |
| 参考音频自动裁剪 | 超长参考音频自动截取到推荐时长后再送识别 |
| 音色的真实删除 | 原版「已保存音色」下拉框的删除不生效，本版改为「×」+ 弹窗确认 + 真实删除 |
| 时间轴音频导出 | 新增导出与 MP3 码率选择 |
| 个人音色命名与管理 | 区分预设音色与自建音色 |
| 运行日志落盘 | 保留上一次运行日志 |
| 明暗主题适配 | 全局明暗主题 |

### 改动

| 项目 | 原版 | 本修改版 |
| --- | --- | --- |
| 页面结构 | 配音 / 声音设计 / 配音历史 / 最佳实践 / 关于 | 本地配音 / 本地音色设计 / **MiniMax 云端 TTS** / 本地配音历史 / 最佳实践 / 关于 |

## 关于语速调节

本版**不捆绑 Rubber Band**，变速由 WSOLA 算法实现。

**已知表现：** 加速（如 1.25×）正常；**减速到 0.8× 左右时可能出现轻微电流音**。
这是时间伸缩算法在拉长音频时的固有特性，不是文件损坏或安装错误。

**建议做法：以 1.0 原速生成**，需要变速时在剪辑软件里处理。
原速输出的音色最准确，这也是本项目推荐的工作流。

## 关于你的 API 密钥

云端语音功能需要你自行提供 MiniMax API Key。本整合包对它的处理方式：

- **包内不含任何密钥**，密钥不随整合包分发；
- 仅在你**明确点击「安全保存」**后才写入磁盘；
- 落盘内容为 **Windows DPAPI 加密后的密文**，不是明文，只有你当前的 Windows 账户能解密；
- 存放在 `%LOCALAPPDATA%\YZYLauncher\VoxCPM2\`，**不在整合包目录内**——
  你复制、移动或分享整合包文件夹时不会带走密钥。
