## 功能

### 本地语音合成

- **本地配音** —— VoxCPM2 本地推理，不联网、不需要 API
- **音色克隆** —— 上传参考音频后自动转写参考文本（SenseVoice），不用手打
- **参考音频自动裁剪** —— 超出推荐时长（10–20 秒）的参考音频自动截取后再识别
- **音色库** —— 内置预设音色；可保存自己的音色并命名，也可真实删除
- **本地音色设计** —— 用文字描述音色特征直接生成，不需要参考音频
- **长文本分段生成** —— 按标点与长度自动切分，规避单次推理的长度限制
- **段间响度对齐** —— 分段拼接前统一各段电平，消除段与段之间的音量跳变
- **多角色配音** —— 一段文本中按角色切换不同音色
- **SRT 字幕配音** —— 导入 `.srt`，按时间轴逐条生成

### 云端语音合成（MiniMax，需自备 API Key）

- **云端配音** —— 调用 MiniMax TTS，本机不需要显卡
- **云端音色克隆** —— 上传音频生成云端 `voice_id`
- **云端音色设计** —— 文字描述生成多个候选音色，试听后择一保存
- **云端音色库** —— 保存的音色在本机留存；删除时云端与本机一并删除
- **模型列表自动拉取** —— 从你账号当前可用的模型中选择
- **字符计数** —— 生成前显示字符数，便于估算调用量
- **行间停顿控制** —— 按行插入可调节的停顿

### 输出与后处理

- **任务队列** —— 多任务排队执行，可中途停止
- **生成历史** —— 分页浏览、按需加载试听；清空时文件移入回收站而非直接抹除
- **字幕识别** —— Whisper 生成字幕
- **时间轴音频导出** —— 导出 WAV / MP3，MP3 可选码率
- **变速** —— WSOLA 时间伸缩（注意事项见下方「关于语速调节」）

### 其他

- 明暗主题适配
- API Key 以 Windows DPAPI 加密存放于用户目录，不在整合包内（详见下文）
- 全进程直连、不走系统代理，避免代理软件拦截本地启动检查与云端 API 请求
- 运行日志落盘，并单独保留上一次运行的日志，便于排查问题

| 个人音色命名与管理 | 区分预设音色与自建音色 |

## 关于语速调节

本版**不捆绑 Rubber Band**，变速由 WSOLA 算法实现。

**已知表现：** 加速（如 1.25×）正常；**减速到 0.8× 左右时可能出现轻微电流音**。
这是时间伸缩算法在拉长音频时的固有特性，不是文件损坏或安装错误。

**建议做法：以 1.0 原速生成**，需要变速时在剪辑软件里处理。
原速输出的音色最准确，这也是本项目推荐的工作流。

## 关于你的 API 密钥

云端语音功能需要你自行提供 MiniMax API Key。本整合包对它的处理方式：

- **包内不含任何密钥**，密钥不随整合包分发；
- 仅在你**明确点击「安全保存」**后才写入磁盘；
- 落盘内容为 **Windows DPAPI 加密后的密文**，不是明文，只有你当前的 Windows 账户能解密；
- 存放在 `%LOCALAPPDATA%\YZYLauncher\VoxCPM2\`，**不在整合包目录内**——
  你复制、移动或分享整合包文件夹时不会带走密钥。
